PROJECT: modern3dconcept Landing Page

GOAL:
Create a modern, high-end industrial landing page for a 3D printing company called "modern3dconcept". The company works with defense industry, prototyping, and mass production. The design must feel premium, technical, and trustworthy — NOT playful or startup-like.

TECH STACK:

- Next.js
- Tailwind CSS
- Framer Motion (animations)
- @react-three/fiber + drei (for 3D model in hero)

STYLE GUIDE:

- Dark theme (black, charcoal, metallic gray)
- Accent color: electric blue or emerald green
- Clean, geometric typography
- Subtle animations only (premium feel)
- Industrial / engineering aesthetic

---

PAGE STRUCTURE:

1. HERO SECTION (Full Screen)

LEFT:

- Title:
  "Fikri Gerçeğe Dönüştüren Endüstriyel 3D Çözümler"

- Subtitle:
  "Prototipten seri üretime, savunma sanayine özel yüksek hassasiyetli üretim çözümleri."

- Buttons:
  [ Projeni İncele ]
  [ Teklif Al ]

RIGHT:

- 3D model (GLB format)
- Slowly rotating
- Lighting: soft + directional
- No zoom, minimal interaction

BACKGROUND:

- Dark gradient + subtle grid overlay

---

2. TRUST BAR

Horizontal strip under hero:

- "Savunma Sanayi Projeleri"

- client logos (grayscale → color on hover)

3D MODEL REQUIREMENTS:

- Format: .glb ONLY
- Optimized (low-poly if possible)
- Industrial/mechanical object (NOT cartoon)
- Slow rotation animation

---

ANIMATION RULES:

- Use Framer Motion
- Avoid over-animation
- Focus on smooth, premium transitions

---

OUTPUT EXPECTATION:

- Fully structured React components
- Tailwind styled
- Clean, modular code
- Hero section includes 3D model integration

---

IMPORTANT:

This is NOT a startup-style colorful site.
This is a high-end industrial engineering brand.
Design must feel like a defense contractor / advanced manufacturing company.
